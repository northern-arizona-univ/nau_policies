# 200352 Curriculum Protocols: Fast Track Policy

## Policy

### Course-Fast Track Eligibility:

In order to be eligible for the Fast Track process, all proposed course changes must be included in the following table.

| **Change** | **Notes** |
| --- | --- |
| Adding a "cross-listing" to an existing course | As long as no content changes are being made to the course and the course number is at the same academic level. |
| Adding, removing, or changing an embedded lab component | As long as contact hours change accordingly and are commensurate with academic policy. |
| Course deletions (deactivations) | As long as all impacted units are notified. |
| Course description | As long as no content changes are being made to the course. |
| Course grading option | Pass/fail only, letter grade only, pass/fail and letter grade option. |
| Course number changes at the same academic level | A lower-division (100-200 level) course remains lower division, and an upper-division (300-400 level) course remains upper-division. |
| Course prefix | Subject/prefix |
| Course prerequisites and/or corequisites | As long as all impacted units are notified. |
| Course repeatability | The ability for students to repeat a course for credit or no longer repeat a course for credit. |
| Course title | As long as no content changes are being made to the course. |
| Reactivation of a previously approved course | As long as no content changes are being made to the course. |
| Removal of a general studies designation. | As long as no content changes are being made to the course. |

### Plan-Fast Track Eligibility

In order to be eligible for the Fast Track process, all proposed plan changes must be included in the following table.

|  |  |
| --- | --- |
| **Change** | **Notes** |

| Undergraduate admission requirements |  |
| Editorial changes to the Academic Description field, the Overview tab, or the Details tab | Excluding changes to the purpose statement or student learning outcomes. |
| Text/requirements | Resulting from any of the Course-Fast Track Changes listed above. |
